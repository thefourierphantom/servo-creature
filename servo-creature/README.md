# Tilt Trial Arena / Mission Breach

An expo-ready, MPU-only arcade game for Raspberry Pi 3B+.
Tilt the wand. React to prompts. Survive Boss mode.

---

## Core Hardware — all you need

| Component | Notes |
|---|---|
| Raspberry Pi 3B+ | host |
| MPU6050 IMU module | I2C, addr 0x68 — tilt wand |
| HDMI monitor | 1280×720 minimum |
| Keyboard | menu / start / calibrate |

Everything else (OLED, dot matrix, PIR, ultrasonic, laser, BT controller) is commented out and optional for future expansion.

---

## Quick Start

### 1. Enable I2C on the Pi

```bash
sudo raspi-config
# → Interface Options → I2C → Enable
```

### 2. Verify the MPU6050 is detected

```bash
i2cdetect -y 1
# Should show  68  in the table
```

### 3. Install dependencies

```bash
cd ~/servo-creature
pip install -r requirements.txt --break-system-packages
```

> On a laptop (mock mode) you only need `pygame` and `PyYAML`.

### 4. Run

```bash
# Pi (real hardware):
python app.py

# Laptop / mock mode (no Pi hardware):
python app.py --mock
# or:
MOCK_HARDWARE=1 python app.py

# Fullscreen expo mode:
python app.py --fullscreen
```

## Keyboard Controls

| Key | Action |
|---|---|
| `ENTER` or `SPACE` | Start / confirm |
| `ESC` | Back to attract / quit session |
| `F2` | Jump directly to Reflex mode |
| `F3` | Jump directly to Boss mode |
| `R` | Recalibrate the MPU6050 |
| `D` | Toggle debug overlay (raw tilt + FPS) |
| `← → ↑ ↓` | Simulate tilt in mock mode |
| `Q` | Quit |

> In attract mode `F1` enters Freeplay for gentle onboarding.

## Calibration

The game will warn you if the wand is uncalibrated.

**In-game:**  Press **R** at any time.  The calibration screen opens, counts down ~150 samples while you hold the wand flat, then returns to where you were.

**From terminal:**
```bash
python tools/test_mpu6050.py --calibrate
```

Offsets are saved to `config/calibration.yaml` and auto-loaded on every launch.

### Axis mapping problems?

If tilting LEFT shows RIGHT on screen, or UP shows DOWN, edit `config/hardware.yaml`:

```yaml
mpu6050:
  swap_axes: false   # true = swap the roll and pitch channels
  invert_x:  false   # true = flip LEFT ↔ RIGHT
  invert_y:  false   # true = flip UP ↔ DOWN
  sensitivity: 1.0   # increase for more responsive, decrease for less
  deadzone_deg: 4.0  # degrees of stillness treated as zero
  threshold_deg: 22.0 # degrees needed to register a direction
```

No code changes needed — just edit the YAML and relaunch.

**How to diagnose:** Press **D** in-game to open the debug overlay.  It shows:
- `game roll/pitch` — the fully mapped values the scoring engine sees
- `raw roll/pitch` — offset-corrected angles before mapping (axis swap / inversion)
- The active mapping flags
- Live FPS

Compare `raw` vs `game` values while tilting to figure out which flags to flip.

## Performance Tuning (Pi 3B+)

Recommended `config/game.yaml` settings for Pi:

```yaml
fps: 30              # 30 is smooth and leaves headroom
mpu_poll_hz: 20      # IMU reads independently of render frame
display:
  fullscreen: false  # set true for expo; adds ~5% overhead
show_fps: true       # near-zero cost; useful to monitor
debug_overlay: false # turn off in expo to save ~1 ms/frame
```

If you still see frame drops:
- Lower `fps` to 25
- Make sure no other processes are hogging the CPU (`top`)
- Disable the desktop compositor: `sudo raspi-config` → Advanced → GL Driver → Legacy

## Game Modes

### Attract
Idle title screen.  Shown at startup and after every session.
- Press `ENTER` → Freeplay
- Press `F2` → Reflex
- Press `F3` → Boss

### Freeplay
Live tilt exploration.  No scoring.  Great for calibration check and new players.
- Roll / Pitch values displayed large in the centre panel
- Idle 60 s → returns to Attract

### Reflex Mode
15 timed prompts (configurable in `game.yaml`).  Each prompt gives you 2.5 s.

| Prompt | What to do |
|---|---|
| `← LEFT` | Tilt wand left (roll) |
| `RIGHT →` | Tilt wand right (roll) |
| `↑ UP` | Pitch wand up (nose up) |
| `↓ DOWN` | Pitch wand down |
| `◉ HOLD` | Keep wand flat and still |
| `❄ FREEZE` | Same as HOLD |
| `≋ SHAKE` | Shake vigorously |

Scoring: 100 pts base + up to 50 pts time bonus, scaled by combo multiplier (×1.0 → ×5.0).

### Boss Mode
20 prompts at 1.6 s each.  Everything from Reflex plus:
- **Axis Inversion** (25% chance): LEFT/RIGHT or UP/DOWN secretly flipped. Badge shown on screen.
- **Fake-outs** (20% chance): display reads `⚠ DODGE LEFT` but correct answer is FREEZE.
  Moving = FAKE result, +2 threat.
- Miss penalty: 30 pts deducted per miss.
- Threat level escalates faster.

## Two-Glove Expansion (Future)

The architecture is ready.  When you want to add a second MPU6050:

1. Wire it with AD0 pulled HIGH → I2C address 0x69.
2. Uncomment `mpu6050_p2` in `config/hardware.yaml`.
3. Add a `player2_tilt` field to `GameState`.
4. Create `src/input/mpu6050_p2_input.py` (or parameterise the existing factory).
5. New mode `src/modes/versus_mode.py` reads both tilt dicts.

No existing files need to change.

## Troubleshooting

**"MPU6050 init failed"** — Run `i2cdetect -y 1`.  Check wiring and confirm I2C is enabled.

**Axes are wrong** — Press D for debug overlay, then edit `config/hardware.yaml` `swap_axes / invert_x / invert_y`.

**Game is laggy** — Lower `fps` to 25 in `game.yaml`.  Disable `debug_overlay`.

**Score won't register** — Increase `sensitivity` or decrease `threshold_deg` in `hardware.yaml`.  Use debug overlay to see live values vs. threshold.

**Calibration doesn't help** — Hold the wand completely flat (USB port side down) during the calibration countdown.  Press R again if needed.
